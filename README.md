### 🌸 Тамагочи Приют — DevOps Курс

Милое веб-приложение в пастельных тонах для управления виртуальным приютом домашних животных (котики 🐱, пёсели 🐶, капибары 🦦 и жирафики 🦒). 

### 🏗️ Архитектура проекта

* **Frontend**: Одностраничное приложение (HTML5, Fetch API). Стили написаны на **SCSS**  и скомпилированы в CSS.
* **Backend**: REST API на фреймворке **FastAPI (Python)**.
* **Database**: Сетевая база данных **PostgreSQL**, развернутая в Docker.

### 🚀 Запуск проекта

Весь стек (база + бэкенд + фронтенд) поднимается одной командой через Docker Compose:

```bash
docker compose up -d --build
```

После запуска:

* Фронтенд — http://localhost:3000
* API — http://localhost:8000/api/pets

Остановить стек (данные в томе сохранятся):

```bash
docker compose down
```

Полностью удалить вместе с данными:

```bash
docker compose down -v
```

Подробности — в [отчёте по Лабораторной работе №2](./reports/lab2/report_2.md).

### 🔐 Секреты и безопасность

Пароли, хеши паролей и приватные ключи **не хранятся в репозитории**. Файлы `auth/`, `ssl/`, `check.sh` и ключи (`*.key`, `*.crt`, `*.pem`) добавлены в `.gitignore`.

Для запуска тестов админки задайте креды через переменные окружения:

```bash
ADMIN_USER=admin ADMIN_PASS=ваш_пароль ./check.sh
```
