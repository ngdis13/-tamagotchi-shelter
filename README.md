# 🌸 Тамагочи Приют 🌸

Милое  веб-приложение в пастельных тонах для управления виртуальным приютом с животными (котики 🐱, пёсели 🐶, капибары 🦦 и жирафики 🦒). 

## 🏗️ Архитектура и стек технологий

Приложение разделено на три независимых слоя (компонента):
1. **Frontend**: Одностраничное приложение (SPA) на чистом HTML5 и JavaScript (Fetch API). Стили написаны на **SCSS** с использованием гибкой методологии и скомпилированы в CSS. 
2. **Backend**: REST API на фреймворке **FastAPI (Python)**. Реализует эндпоинты для добавления, чтения, обновления (кормления) и удаления (отпускания на волю) питомцев. Включает логику автоматического падения сытости на фронтенде.
3. **Database**: Реляционная сетевая база данных **PostgreSQL**. Запускается в изолированном контейнере Docker и обеспечивает постоянное хранение состояния приюта.

## 🚀 Инструкция по локальному запуску

Для работы приложения необходимо одновременно поднять базу данных, запустить сервер бэкенда и открыть хост фронтенда.

### Шаг 1. Запуск базы данных в Docker 
Убедитесь, что у вас запущен **Docker Desktop**. Открыв терминал (Консоль / PowerShell / Terminal Mac), выполните команду для запуска контейнера базы данных на стандартном порту `5432`:

```bash
docker run --name tama-db -e POSTGRES_USER=user -e POSTGRES_PASSWORD=password -e POSTGRES_DB=tamagotchi_db -p 5432:5432 -d postgres
```

### Шаг 2. Запуск Бэкенда (FastAPI)
1. Откройте новое окно терминала и перейдите в папку бэкенда:
   ```bash
   cd backend
   ```
2. Установите необходимые Python-зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Запустите сервер веб-приложения с передачей переменной окружения `DATABASE_URL`:
   * **Для Windows (Command Prompt / cmd):**
     ```cmd
     set DATABASE_URL=postgresql://user:password@127.0.0.1:5432/tamagotchi_db
     uvicorn main:app --reload
     ```
   * **Для Windows (PowerShell):**
     ```powershell
     $env:DATABASE_URL="postgresql://user:password@127.0.0.1:5432/tamagotchi_db"
     uvicorn main:app --reload
     ```
   * **Для Linux / macOS / Git Bash:**
     ```bash
     DATABASE_URL="postgresql://user:password@127.0.0.1:5432/tamagotchi_db" uvicorn main:app --reload
     ```
   *Сервер бэкенда поднимется по адресу: `http://localhost:8000`*

### Шаг 3. Запуск и компиляция Фронтенда
1. Откройте новое окно терминала и перейдите в папку фронтенда:
   ```bash
   cd frontend
   ```
2. Скомпилируйте файлы стилей из SCSS в рабочий CSS через кроссплатформенную утилиту `npx` (требуется установленный Node.js):
   ```bash
   npx sass style.scss style.css
   ```
   *Если вы хотите, чтобы стили пересобирались автоматически при каждом сохранении файла, добавьте флаг слежки:* `npx sass --watch style.scss:style.css`
3. Запустите локальный веб-сервер для раздачи статических файлов фронтенда на порту `3000`:
   * **Вариант с Python (универсальный для любой ОС):**
     ```bash
     python -m http.server 3000
     ```
     *(Если команда выдает ошибку на Mac/Linux, используйте `python3 -m http.server 3000`)*
   * **Вариант с Node.js (если нет Python):**
     ```bash
     npx serve -l 3000 .
     ```
   *Интерфейс приюта теперь доступен в браузере по адресу: **`http://localhost:3000`***

## 🧪 Тест-драйв приюта (Проверка CRUD-цикла)

1. **Рождение легенды (Create)** 🐣  
   Заходим на наш уютный хост фронтенда. В левой панели придумываем имя (например, `Мелман`), выбираем из списка `Жирафик 🦒` и жмем «Приютить». Справа мгновенно материализуется эстетичная оранжевая карточка. Малыш дома, но пока немного голоден (сытость 50%).

2. **Проверка на прочность (Read)** 🔄  
   Устраиваем стресс-тест памяти: полностью обновляем страницу. Наш жираф никуда не убегает! Бэкенд успешно сбегал в Docker к PostgreSQL, бережно поднял записи и отрисовал Мелмана обратно. 

3. **Время вкусняшек! (Update)** 🥦  
   Нажимаем кнопку «Покормить». Сытость увеличивается на 10%, а в базе данных обновляются циферки. Если раскормить жирафика больше 80%, сработает магия фронтенда — смайлик превратится в довольного `🥦🦒`, жующего сочные листики! 
   *Включен эффект Тамагочи, и Мелман самостоятельно теряет по 5% сытости каждые 4 секунды, если о нем забыть.*
