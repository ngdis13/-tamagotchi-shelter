### 🌸 Тамагочи Приют — DevOps Курс

Милое веб-приложение в пастельных тонах для управления виртуальным приютом домашних животных (котики 🐱, пёсели 🐶, капибары 🦦 и жирафики 🦒). 

### 🏗️ Архитектура проекта

* **Frontend**: Одностраничное приложение (HTML5, Fetch API). Стили написаны на **SCSS**  и скомпилированы в CSS.
* **Backend**: REST API на фреймворке **FastAPI (Python)**.
* **Database**: Сетевая база данных **PostgreSQL**, развернутая в Docker.
